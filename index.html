01 / FUNDAMENTOS

¿Qué es Git?

Git es un sistema de control de versiones que permite registrar los cambios de un proyecto y recuperar versiones anteriores.

📁

Repositorio

Carpeta donde Git guarda los archivos y el historial del proyecto.

📸

Commit

Una captura de los cambios realizados en un momento determinado.

🌿

Branch

Una rama independiente para trabajar en nuevas funcionalidades.

02 / PLATAFORMA

¿Qué es GitHub?

GitHub es una plataforma online que permite almacenar repositorios Git y colaborar con otros desarrolladores.

¿Para qué sirve?

  • ✓ Guardar proyectos en la nube.
  • ✓ Trabajar en equipo.
  • ✓ Revisar cambios de código.
  • ✓ Crear ramas y solicitudes de cambios.
  • ✓ Compartir proyectos con el mundo.

03 / REFERENCIA RÁPIDA

Comandos esenciales

Busca y copia los comandos que necesitas.

INICIO

Inicializar repositorio

Crea un repositorio Git en tu carpeta.

git init
INICIO

Clonar repositorio

Descarga un repositorio remoto.

git clone URL
CAMBIOS

Revisar estado

Muestra los archivos modificados.

git status
CAMBIOS

Agregar archivos

Prepara todos los archivos modificados.

git add .
CAMBIOS

Guardar cambios

Crea un commit con un mensaje.

git commit -m "mensaje"
CAMBIOS

Ver historial

Consulta los commits realizados.

git log --oneline
RAMAS

Crear una rama

Crea una nueva rama de trabajo.

git branch nueva-rama
RAMAS

Cambiar de rama

Cambia a otra rama existente.

git switch nueva-rama
RAMAS

Fusionar ramas

Integra otra rama en la actual.

git merge nueva-rama
GITHUB

Conectar repositorio

Asocia tu repositorio local con GitHub.

git remote add origin URL
GITHUB

Subir cambios

Envía los commits a GitHub.

git push -u origin main
GITHUB

Descargar cambios

Obtiene e integra los cambios remotos.

git pull origin main
GITHUB

Consultar repositorios remotos

Muestra las conexiones remotas.

git remote -v

Tu primer proyecto en GitHub

Sigue estos pasos para publicar un proyecto.

01

Inicializa Git

02

Agrega tus archivos

git add .
03

04

Conecta GitHub

05

Sube tu proyecto

git push -u origin main

Nota: reemplaza URL por la dirección HTTPS de tu repositorio de GitHub. Si tu rama tiene otro nombre, ajusta main.
